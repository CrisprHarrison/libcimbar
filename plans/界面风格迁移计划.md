## 🔄 API对照表

| 功能 | 旧版API（你的） | 新版API（目标） |
|------|---------------|----------------|
| **初始化** | `_initialize_GL(w, h)` | 保持不变 |
| **编码初始化** | 无 | `_cimbare_init_encode(fn, len, mode)` |
| **编码数据** | `_encode(offset, len, mode)` | `_cimbare_encode(offset, len)` |
| **渲染** | `_render()` | `_cimbare_render()` |
| **下一帧** | `_next_frame()` | `_cimbare_next_frame()` |
| **配置** | `_configure(a, b, c, is_4c)` | `_cimbare_configure(mode, -1)` |
| **获取宽高比** | 无 | `_cimbare_get_aspect_ratio()` |
| **旋转窗口** | 无 | `_cimbare_rotate_window(bool)` |
| **缓冲区大小** | 无 | `_cimbare_encode_bufsize()` |
