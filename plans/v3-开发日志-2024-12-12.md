## 📋 项目概述

为 web/pack/v3 添加 App Store 风格的流动渐变背景，并优化界面交互体验。

## 🎯 主要功能

### 1. 流动渐变背景
基于 [`plans/app-store-gradient-effect-documentation.md`](plans/app-store-gradient-effect-documentation.md) 实现的多层流动背景效果。

#### 技术实现
- **双层结构**: 旋转层 + 模糊层
- **背景图片**: [`400x400bb-75.jpg`](web/pack/v3/400x400bb-75.jpg)
- **动画速度**: 60秒完成一圈旋转（用户优化后的速度）
- **模糊效果**: 80px 强烈模糊

#### 视觉参数
```css
/* 旋转层 */
- opacity: 0.2 (用户优化)
- blur: 80px (用户优化)
- animation: 60s (用户优化)

/* 模糊层 */
- opacity: 0.3
- blur: 80px
```

### 2. 导航栏圆形按钮设计

#### 按钮样式
- **形状**: 圆形（60x60px）
- **背景**: 半透明毛玻璃效果 `rgba(255, 255, 255, 0.1)`
- **边框**: `1px solid rgba(255, 255, 255, 0.2)`
- **间距**: 20px
- **效果**: `backdrop-filter: blur(10px)`

#### 选中态
- **背景**: `rgba(255, 255, 255, 0.5)` - 50% 不透明度
- **文字**: 黑色 `#000`

#### 按钮列表
- File (文件选择)
- B (模式)
- Bm (模式)
- 4C (模式)
- ~~Fullscreen~~ (已删除)

### 3. 胶囊状态与动态展开

#### 初始状态（无文件）
```css
#dragdrop {
  height: 80px;
  margin-top: 120px;
  border-radius: 40px;
  display: flex;
  align-items: center;
  justify-content: center;
}
```

**显示内容**: "【 Tap to start 】"
- 水平和垂直居中
- `white-space: nowrap` 防止换行

#### 展开状态（有文件）
```css
#dragdrop.has-file {
  height: calc(100vh - 30px);
  margin-top: 15px;
  border-radius: 25px;
}
```

**触发条件**: 
- 用户选择文件后
- JavaScript 添加 `.has-file` 类

### 4. 毛玻璃风格统一

所有容器使用统一的毛玻璃效果：
```css
background-color: rgba(255, 255, 255, 0.1);
backdrop-filter: blur(10px);
border: 1px solid rgba(255, 255, 255, 0.2);
```

应用于：
- 导航按钮
- Canvas 容器（dragdrop）

## 🐛 问题修复记录

### 1. 文件选择功能失效
**问题**: 点击 File 按钮无法打开文件选择框

**原因**: 导航栏缺少明确的 z-index 层级设置

**解决方案**:
```css
#nav-container {
  position: relative;
  z-index: 10;
}
```

**Commit**: `62d52d3`

### 2. 模糊层不显示
**问题**: 只看到旋转的清晰图片，没有模糊效果

**原因**: 
1. 旋转层完全遮挡模糊层
2. `mix-blend-mode: overlay` 在 `isolation: isolate` 容器中不工作

**解决方案**:
1. 调整 HTML 元素顺序（模糊层在前）
2. 移除 `mix-blend-mode`
3. 旋转层设置半透明 `opacity: 0.7`（后优化为 0.2）
4. 添加 WebKit 前缀 `-webkit-filter`

**Commit**: `6731916`

### 3. Canvas 容器超出页面
**问题**: dragdrop 总有一小截在页面外面

**原因**: `height: 95%` + `margin` + `padding` 导致总高度超过视口

**解决方案**:
```css
height: calc(100vh - 30px);
box-sizing: border-box;
```

**Commit**: `2b0fe59`

### 4. 文字换行问题
**问题**: 在 Bm 模式下"【 Tap to start 】"被挤压换行

**解决方案**:
```css
.dragdrop::before {
  white-space: nowrap;
}
```

**Commit**: `5a14fc8`

### 5. 模式切换时 dragdrop 变化
**问题**: 点击 B/Bm/4C 按钮时，dragdrop 会发生变化

**原因**: `setMode()` 调用 `resize()`，即使没有文件也会重新计算 Canvas 尺寸

**解决方案**:
```javascript
resize: function () {
  var dragdrop = document.getElementById('dragdrop');
  if (!dragdrop.classList.contains('has-file')) {
    return;
  }
  // ... 原有逻辑
}
```

**Commit**: `5a14fc8`

## 🎓 经验总结

### 1. 层叠顺序很重要
- 模糊层必须在旋转层之前（HTML 顺序）
- 使用 z-index 明确层级关系

### 2. 状态管理要清晰
- 使用类名（`.has-file`）管理状态
- 在关键函数中检查状态

### 3. 性能优化不可少
- GPU 加速（`translateZ(0)`）
- 避免不必要的 resize
- 使用 `will-change` 提示浏览器

### 4. 用户反馈很宝贵
- 初始设计 vs 最终效果差异很大
- 迭代优化让效果更完美
