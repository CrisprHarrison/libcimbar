### 2. CSS 样式实现

#### 2.1 背景容器样式

```css
/* 流动背景容器 */
.gradient-background {
  position: fixed;
  inset: 0;
  width: 100%;
  height: 100%;
  overflow: hidden;
  z-index: -1;
  background-color: black;
  isolation: isolate;
}
```

**关键点**:
- `position: fixed` - 固定在视口，不随滚动移动
- `inset: 0` - 覆盖整个视口
- `z-index: -1` - 位于所有内容之下
- `isolation: isolate` - 创建新的层叠上下文，避免混合模式影响其他元素

#### 2.2 旋转渐变层

```css
/* 旋转渐变层 */
.gradient-background .rotate {
  position: absolute;
  inset: -50%;
  background: 
    radial-gradient(
      circle at 30% 50%,
      rgba(255, 255, 255, 0.15) 0%,
      transparent 50%
    ),
    radial-gradient(
      circle at 70% 50%,
      rgba(255, 255, 255, 0.1) 0%,
      transparent 50%
    ),
    url('400x400bb-75.jpg');
  background-size: cover;
  background-position: center;
  animation: rotate-gradient 20s linear infinite;
  transform-origin: center center;
  will-change: transform;
}

@keyframes rotate-gradient {
  0% {
    transform: rotate(0deg) scale(1.5);
  }
  100% {
    transform: rotate(360deg) scale(1.5);
  }
}
```

**关键点**:
- `inset: -50%` - 扩展到容器外，避免旋转时出现空白
- `scale(1.5)` - 确保旋转时始终覆盖容器
- 多个径向渐变叠加在图片上，创造光晕效果
- 20秒完整旋转周期（中速）
- `will-change: transform` - GPU 加速优化

#### 2.3 模糊层

```css
/* 模糊层 */
.gradient-background .blur {
  position: absolute;
  inset: 0;
  background: url('400x400bb-75.jpg');
  background-size: cover;
  background-position: center;
  filter: blur(60px);
  opacity: 0.6;
  mix-blend-mode: overlay;
}
```

**关键点**:
- `filter: blur(60px)` - 创建强烈的模糊效果
- `mix-blend-mode: overlay` - 与下层混合，增强色彩饱和度
- `opacity: 0.6` - 控制混合强度

#### 2.4 性能优化

```css
/* 性能优化 */
.gradient-background .rotate,
.gradient-background .blur {
  transform: translateZ(0);
  backface-visibility: hidden;
}

/* 减少动画偏好用户的动画 */
@media (prefers-reduced-motion: reduce) {
  .gradient-background .rotate {
    animation: none;
  }
}
```

## ⚠️ 注意事项

### 1. 图片路径
- 确保 `url('400x400bb-75.jpg')` 路径正确
- 图片应与 HTML 文件在同一目录

### 2. 性能考虑
- 模糊效果可能在低端设备上影响性能
- 可以通过调整 `blur(60px)` 值来优化
- 移动设备可以考虑降低模糊强度

### 3. 浏览器兼容性
- `backdrop-filter` 需要较新的浏览器
- `mix-blend-mode` 在旧版 IE 不支持
- 提供了 `@media (prefers-reduced-motion)` 降级方案

### 4. 层级关系
- 背景层 `z-index: -1` 确保在最底层
- 不影响导航栏和 Canvas 的交互
- `isolation: isolate` 防止混合模式影响其他元素

## 🔄 可选调整

### 调整动画速度
```css
/* 快速 (15秒) */
animation: rotate-gradient 15s linear infinite;

/* 慢速 (30秒) */
animation: rotate-gradient 30s linear infinite;
```

### 调整模糊强度
```css
/* 轻度模糊 */
filter: blur(40px);

/* 强烈模糊 */
filter: blur(80px);
```

### 调整光晕效果
```css
/* 更明显的光晕 */
radial-gradient(
  circle at 30% 50%,
  rgba(255, 255, 255, 0.25) 0%,  /* 增加不透明度 */
  transparent 50%
)

/* 更柔和的光晕 */
radial-gradient(
  circle at 30% 50%,
  rgba(255, 255, 255, 0.08) 0%,  /* 降低不透明度 */
  transparent 50%
)
```

### 移动端优化
```css
@media (max-width: 768px) {
  .gradient-background .blur {
    filter: blur(40px);  /* 降低模糊强度 */
    opacity: 0.4;        /* 降低不透明度 */
  }
  
  .gradient-background .rotate {
    animation-duration: 30s;  /* 减慢动画速度 */
  }
}
```
